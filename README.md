# CS-330-Computational-Graphics-and-Visualization
Artifacts and reflection from CS 330 Computational Graphics and Visualization.


How do I approach designing software?

This project helped me get better at breaking a larger idea into smaller parts. For my 3D scene, I started by looking at the reference image and deciding which basic shapes could be used to recreate each object. I then worked through the scene one object at a time instead of trying to build the entire desk setup at once.
As the project progressed, I also learned that design is not only about getting the basic structure correct. Smaller details such as object placement, textures, materials, and lighting made a very noticeable difference in how the finished scene looked. In future projects, I can use the same approach by starting with the main structure first and then refining the smaller details through testing and feedback.

How do I approach developing programs?

One of the biggest development strategies I used was building and testing the project in smaller sections. I added objects individually and made sure they worked before moving on to the next part of the scene. As the project became larger, I also separated the objects into their own rendering functions, which made the code easier to troubleshoot and update.
Iteration was a large part of the project. Some things worked technically but did not look correct when I viewed them in the scene. I had to make several adjustments to object proportions, textures, and lighting throughout the milestones. For example, I changed how the monitor texture was applied and adjusted the lighting after parts of the monitor became too dark from certain camera angles. By the end of the project, I was more comfortable testing smaller changes and refining them instead of expecting the first version to be final.

How can computer science help me in reaching my goals?

Computational graphics gave me another way to practice programming while also seeing the results of my changes visually. I gained more experience with C++, debugging, and organizing code. These are skills I can continue building on in future courses, even if the projects are not specifically focused on graphics.
Building on these skills will continue to be useful professionally. The project involved breaking a larger problem into smaller pieces, troubleshooting issues, and organizing code so it is easier to maintain. I could also see visualization being useful in areas such as dashboards, reporting, simulations, or other systems where presenting information visually can make it easier to understand.
